# Python Data Analysis

A practical portfolio project demonstrating data analysis with Python, public datasets, JSON, exploratory analysis, visualisation, and technical documentation.

## Purpose

This repository demonstrates an end-to-end workflow for turning structured data into clear findings:

```text
Raw Data / JSON
      ↓
Data Inspection
      ↓
Cleaning & Validation
      ↓
Exploratory Data Analysis
      ↓
Visualisation
      ↓
Findings
      ↓
Actionable Recommendations
      ↓
Technical Documentation
```

## Skills Demonstrated

- Python
- pandas
- NumPy
- Data cleaning and validation
- Exploratory data analysis (EDA)
- JSON handling
- Data visualisation
- Statistical reasoning
- Technical documentation
- Communicating findings clearly

## Dataset

The initial demonstration uses a small synthetic sales dataset stored as JSON. It is intentionally simple so that the analysis workflow and reasoning can be inspected easily.

## Questions

The analysis investigates:

- Which products generate the most revenue?
- Which regions contribute the most sales?
- How does revenue vary over time?
- Which products have stronger sales volume but lower revenue?
- What findings could inform business decisions?

## Scope

This is a portfolio demonstration using synthetic data. It does not represent confidential business data or client analysis.
